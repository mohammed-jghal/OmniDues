# Security Policy

## Reporting a vulnerability

If you find a security vulnerability in the documentation or in the system it describes, report it privately. Do not open a public issue.

Contact the owner through LinkedIn only:

- LinkedIn: [linkedin.com/in/mohammed-jghal-884367335](https://www.linkedin.com/in/mohammed-jghal-884367335)

No email channel is offered. Include a description of the issue, the affected document or component, and steps to reproduce it where applicable. The owner will acknowledge the report and assess it before any public disclosure.
